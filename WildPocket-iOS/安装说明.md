# 《旷野》iOS 安装说明

更新：2026-09-22

适用：iPhone，iOS 16 或更高。App 内置全部照片、故事和叫声，安装后完全不需要联网。

## 为什么还不能直接装

iOS 只允许安装签过名的 App。签名必须用你自己的 Apple ID，我没有你的账号，所以交付的是**未签名的 IPA 和可直接用 Xcode 打开的工程**。下面任选一种方式，用你的 Apple ID 签名一次即可。

## 四种安装方式对比

| 方式 | 费用 | 有效期 | 需要 | 适合 |
|---|---|---|---|---|
| A. Xcode 直接安装 | 免费 | 7 天 | Mac、数据线、Apple ID | 自己用，**推荐** |
| B. IPA 加 Sideloadly | 免费 | 7 天 | Mac、数据线、Apple ID | 不想打开 Xcode |
| C. TestFlight | 99 美元每年 | 90 天 | 付费开发者账号 | 发给朋友一起用 |
| D. App Store 上架 | 99 美元每年 | 长期 | 付费开发者账号、审核 | 公开发布 |

免费账号的 7 天到期后 App 会打不开。重新安装一次即可，覆盖安装会保留"见过"记录。

## 安装前的手机准备（方式 A、B 都要做）

1. 用数据线连接 iPhone 和 Mac。
2. iPhone 上弹出"要信任此电脑吗"，点"信任"，并输入手机锁屏密码。
3. 打开"设置 → 隐私与安全性"，拉到最下面，点"开发者模式"，打开开关。
4. 按提示重启 iPhone，重启后再确认一次"打开"。
5. 如果找不到"开发者模式"这一项，先完成下面方式 A 的第一次运行，这一项就会出现。

## 方式 A：用 Xcode 直接安装（推荐）

1. 打开 Xcode，进入菜单"Xcode → Settings → Accounts"。
2. 点左下角加号，选 Apple ID，登录你的账号。
3. 双击打开 `WildPocket-iOS/WildPocket.xcodeproj`。
4. 在左侧点最上面的 `WildPocket` 项目，再点中间的 target `WildPocket`。
5. 进入 **Signing & Capabilities** 标签。
6. 勾选 **Automatically manage signing**。
7. **Team** 下拉里选你的个人团队，名字形如"你的名字（Personal Team）"。
8. 把 **Bundle Identifier** 改成独一无二的值，例如 `com.你的名字.wildpocket`。默认值 `com.wildpocket.eastafrica` 可能已被别人占用，会报错。
9. 窗口顶部的设备栏，点开选择你连接的 iPhone。
10. 按 ⌘R，或点左上角的三角形运行。第一次会编译一到两分钟。
11. 手机上出现 App 后，如果提示"不受信任的开发者"：
    - 打开"设置 → 通用 → VPN 与设备管理"。
    - 在"开发者 App"下点你的 Apple ID。
    - 点"信任"，再点一次确认。
12. 回到主屏幕，点"旷野"图标打开。

以后想更新 App，见下面"更新 App"一节。

## 方式 B：未签名 IPA 加 Sideloadly

1. 从 sideloadly.io 下载并安装 Sideloadly。
2. 手机准备好并连接 Mac，见上面"安装前的手机准备"。
3. 打开 Sideloadly，确认识别到你的 iPhone。
4. 把 `WildPocket-iOS/WildPocket-unsigned.ipa` 拖进 Sideloadly 窗口。
5. 在 Apple ID 一栏输入你的 Apple ID，点 Start。
6. 按提示输入 Apple ID 密码，如果开了双重认证，再输入手机收到的验证码。
7. 等待安装完成，手机上会出现"旷野"。
8. 按方式 A 第 11 步信任开发者，然后打开 App。

如果想避免每 7 天手动重装，可以改用 AltStore（altstore.io），它能在同一网络下自动续签。

## 方式 C：TestFlight

1. 加入 Apple Developer Program，费用 99 美元每年。
2. 在 Xcode 里选你的付费团队，Bundle Identifier 用你在后台登记的值。
3. 设备栏选"Any iOS Device (arm64)"。
4. 菜单 Product → Archive。
5. 完成后在弹出的 Organizer 里点 Distribute App，选 App Store Connect，点 Upload。
6. 登录 App Store Connect，进入 TestFlight，添加测试员的邮箱。
7. 测试员在 iPhone 安装 TestFlight，接受邀请后即可安装，有效期 90 天。

## 方式 D：App Store 上架

在方式 C 的基础上，补齐截图、隐私说明和审核信息，然后提交审核。文案建议见 `README.md`。审核时请说明：

- 全部内容内置，无网络也能使用。
- 有本地收集功能，不是单纯的网页外壳。
- 不收集个人数据，"见过"记录只保存在设备本地。

## 装好后的自检清单

请在真机上依次检查：

1. 首页地点和日间夜间筛选可用，地点和时段栏在滚动时吸顶。
2. 点开一种动物，详情页铺满屏幕，能左右滑动看 3 张照片，"见过"按钮固定在底部。
3. 点有叫声的动物（如狮子）的圆形播放键能出声，再点暂停。静音键打开时也应出声。
4. 点右侧 ⓘ 能展开录音说明、作者和许可。
5. 打开飞行模式，杀掉 App 再打开，照片和叫声仍可用。
6. 标记几个"见过"，到"我的"页确认进度，杀掉 App 再打开，记录仍在。
7. 刘海和底部横条区域没有文字被遮挡。

## 已知限制

- **叫声：** 38 种动物有叫声，17 种暂时没有，因为开放许可的来源里找不到对应的真实录音。名单：汤氏瞪羚、格兰特瞪羚、托皮转角牛羚、水羚、柯氏犬羚、大捻角羚、长颈羚、普通小羚羊、薮羚、大耳狐、蜜獾、土狼、非洲灵猫、非洲麝猫、尼罗鳄、尼罗巨蜥、普通鸵鸟。
- **近缘种：** 东非狒狒用的是近缘种黄狒狒的叫声，页面上已明确标注。
- **记录存放：** "见过"记录存在 App 内嵌网页的本地存储里。日常使用杀进程不会丢，但删除 App 会清空全部记录。系统在极端缺空间时也可能清理它。
- **重装：** 用同一个 Bundle Identifier 覆盖安装会保留记录，换了标识或先删除再装则不会。
- **屏幕：** 只做了 iPhone 竖屏，没有针对 iPad 和横屏设计。

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示"无法验证 App"或"不受信任的开发者" | 见方式 A 第 11 步 |
| 找不到"开发者模式" | 先用 Xcode 把 App 装到手机一次，选项才会出现 |
| Xcode 提示 Bundle Identifier 不可用 | 换一个更独特的值 |
| Xcode 提示 No account 或 No signing certificate | 确认已在 Accounts 登录，并在 Signing 里选了 Team |
| 手机在设备栏里看不到 | 换数据线、解锁手机、重新点"信任此电脑" |
| 超过 7 天打不开 | 免费账号的限制，重新安装即可 |
| 叫声没有声音 | 检查音量和蓝牙耳机连接，并确认该动物有叫声 |
| Xcode 编译失败 | 这个工程刚刚才第一次编译，如果遇到，把完整报错发给我 |
